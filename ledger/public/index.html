What it is

Scrub is a robot arm that passes instruments when you ask out loud.

It picks the tool from the tray and holds it out, handle first, slowing as it nears the handoff point. It lets go when you pull, then goes home on its own.

Instruments go back to the tray by hand. Scrub keeps the count and checks it with the camera.

The tray has three instruments: a scalpel, a hemostat and Mayo scissors.

A research prototype, not a medical device. Scrub never touches the patient. A clinic version would run under a sterile drape on a medical-grade arm, like today's surgical robots, with the trays and tools sterilized as usual. We don't claim it's sterile.

How it works

you speak
  -> ElevenLabs (speech to text, and the spoken reply)
  -> voice/ (Gemini turns the words into one command from the current tray)
  -> controller/ -> arm/ -> SO-101
     vision/ (Perceptron reads the tray for the count)
  -> ledger/ (MongoDB) + this page
  1. ElevenLabs hears the words. Gemini turns them into one command from the current tray, and asks back when a request could mean two instruments.
  2. Perceptron's vision API reads the tray for the count check.
  3. Only the controller moves the arm. Each pick is a skill we taught it from our recorded demonstrations.
  4. The ledger keeps the count and the results below. Simulated and fake-arm runs are left out of every number.
