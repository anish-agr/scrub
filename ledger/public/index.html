What it is

Scrub is a robot arm that passes instruments when you ask out loud.

It picks the tool from the tray and brings it to an open hand, handle first. A scalpel goes to a fixed safe spot instead of hand to hand.

This demo is the operating room tray first, then the robotics bench. Same code, a different tray file.

How it works

phone on speaker
  -> Photon number -> ElevenLabs voice agent -> voice/ (Gemini turns words into a command)
                                                   |
                                                   v
vision/ (camera: tray state + hand position) -> controller/ -> arm/ -> Isaac 0.5 (Perceptron) -> SO-101
                                                   |
                                                   v
                                    ledger/ (MongoDB) + dashboard/ (web page)
  1. A phone on speaker calls the Photon number.
  2. ElevenLabs hears the words. Gemini turns them into one command from the current tray.
  3. The camera reports the tray and the open hand.
  4. Only the controller moves the arm. The Perceptron model runs on the SO-101.
  5. This page and the ledger keep the count and the tables.
